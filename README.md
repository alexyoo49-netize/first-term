# 첫 번째 임기

통일 직후 대통령이 되어 국가를 운영하는 한국어 정치 시뮬레이션 프로토타입입니다.

- 6명의 대통령 캐릭터와 4개의 통일 시나리오
- 8개 부처와 10개 정책의 예산 조절
- 정치적 경쟁자, 지역 사건, 언론, 시위와 정치 공작
- 4명의 참모와 현장 파견
- 10턴 뒤 선거, 한 판 약 10분

역사적 인물의 능력, 대사와 통일 이후 사건은 게임을 위해 만든 가상 설정입니다.

처음 플레이 안내와 사건 해설, 현재 상황에 맞춘 참모 조언을 제공합니다. 계엄은 상단 **계엄** 메뉴에서 선포하거나 해제할 수 있습니다.

사건 보고는 누가 어떤 행동을 했는지 설명하고, 국채나 자치권 같은 용어에는 뜻을 붙였습니다. 새 사건이 발생하면 붉은 경고창이 나타나고 경고 표시가 세 번 점멸합니다. 같은 보고를 다시 열 때는 점멸하지 않으며, 동작 줄이기 설정을 사용하면 정적인 경고로 표시합니다.

새 게임은 10턴입니다. 업데이트 전에 진행하던 저장은 갑자기 종료되지 않도록 기존 20턴 규칙을 유지합니다.

## 실행

[게임 바로 하기](https://alexyoo49-netize.github.io/first-term/)를 열면 바로 플레이할 수 있습니다. 게임 진행은 같은 브라우저의 로컬 저장소에 자동 저장됩니다. 다른 기기와 동기화되지는 않습니다.

로컬 실행:

```sh
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.

## 수정과 빌드

`src/`에 게임 규칙, 사건과 인터페이스 소스가 있습니다. `layout.html`은 스타일, 글꼴과 초상을 포함합니다. `page-template.html`은 독립 실행과 브라우저 저장을 담당합니다.

```sh
python build.py
```

Python 3.9 이상이 필요하며 별도 패키지는 없습니다. 생성된 `index.html`을 소스 변경과 함께 커밋합니다. GitHub Pages는 `main` 브랜치의 루트에서 배포합니다.

게임 규칙 검증은 Node.js에서 `node test-game.cjs`로 실행합니다. 240판의 플레이, 계엄과 탄핵, 10턴 종료, 기존 20턴 저장 호환, 사건별 참모 조언을 확인합니다.

이미지와 게임 글꼴은 내장되어 있습니다. 아이콘과 도움말 배치 라이브러리는 버전이 고정된 CDN에서 로드합니다.

# 첫 번째 임기

통일 직후 대통령이 되어 국가를 운영하는 한국어 정치 시뮬레이션 프로토타입입니다.

- 6명의 대통령 캐릭터와 4개의 통일 시나리오
- 8개 부처와 10개 정책의 예산 조절
- 정치적 경쟁자, 지역 사건, 언론, 시위와 정치 공작
- 4명의 참모와 현장 파견
- 20턴 뒤 선거, 한 판 약 10분

역사적 인물의 능력, 대사와 통일 이후 사건은 게임을 위해 만든 가상 설정입니다.

## 실행

GitHub Pages 주소를 열면 바로 플레이할 수 있습니다. 게임 진행은 같은 브라우저의 로컬 저장소에 자동 저장됩니다. 다른 기기와 동기화되지는 않습니다.

로컬 실행:

```sh
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.

## 수정과 빌드

`src/`에 게임 규칙, 사건과 인터페이스 소스가 있습니다. `layout.html`은 스타일, 글꼴과 초상을 포함합니다. `page-template.html`은 독립 실행과 브라우저 저장을 담당합니다.

```sh
python build.py
```

Python 3.9 이상이 필요하며 별도 패키지는 없습니다. 생성된 `index.html`을 소스 변경과 함께 커밋합니다. GitHub Pages는 `main` 브랜치의 루트에서 배포합니다.

이미지와 게임 글꼴은 내장되어 있습니다. 아이콘과 도움말 배치 라이브러리는 버전이 고정된 CDN에서 로드합니다.

## 출처

- 인터페이스 참고: [Democracy 4](https://www.positech.co.uk/democracy4/). 게임 코드는 별도로 구현했으며 원작의 이미지나 코드를 포함하지 않습니다.
- 글꼴: [Pretendard](https://github.com/orioncactus/pretendard), SIL Open Font License. 수정한 부분 집합은 `First Term Sans`로 이름을 변경했으며 라이선스 전문을 동봉했습니다.
- 참모 초상과 지역 배경 출처는 게임의 자료실에서 확인할 수 있습니다.
- 대통령 초상은 게임용 생성 이미지입니다.

# 첫 번째 임기

통일 직후 대통령이 되어 국가를 운영하는 한국어 정치 시뮬레이션 프로토타입입니다.

- 6명의 대통령 캐릭터와 4개의 통일 시나리오
- 8개 부처와 10개 정책의 예산 조절
- 정치적 경쟁자, 지역 사건, 언론, 시위와 정치 공작
- 4명의 참모와 현장 파견
- 10턴 뒤 선거, 한 판 약 10분

역사적 인물의 능력, 대사와 통일 이후 사건은 게임을 위해 만든 가상 설정입니다.

처음 플레이 안내와 사건 해설, 현재 상황에 맞춘 참모 조언을 제공합니다. 계엄은 상단 **계엄** 메뉴에서 선포하거나 해제할 수 있습니다.

시작 화면의 **게임 설명 읽기**와 플레이 중 상단 **게임 설명**에서 조작 방법, 네 시나리오의 배경과 초반 운영 방향, 10개 정책의 예산과 효과, 위험 수치의 계산 방식을 읽을 수 있습니다. 정책 예시는 현재 인물과 게임 상태를 기준으로 계산하며, 해설을 읽어도 예산이나 진행 상태는 바뀌지 않습니다. 시나리오의 초기 수치는 실제 통일을 예측한 통계가 아닌 가상 게임 설정입니다.

시나리오 선택에는 지금 가장 큰 문제, 유리한 점, 첫 행동과 실제 시작 수치를 표시합니다. 사건 보고는 상황 요약과 대통령이 결정할 일을 먼저 보여주며, 상세 보고와 용어 설명은 펼쳐 읽을 수 있습니다.

사건 보고는 누가 어떤 행동을 했는지 설명하고, 국채나 자치권 같은 용어에는 뜻을 붙였습니다. 새 사건이 발생하면 붉은 경고창이 나타나고 경고 표시가 세 번 점멸합니다. 같은 보고를 다시 열 때는 점멸하지 않으며, 동작 줄이기 설정을 사용하면 정적인 경고로 표시합니다.

국정 지도의 지표, 지지율, 재정 수치를 누르거나 상단 **성과**를 열면 27개 지표의 변화 그래프를 볼 수 있습니다. 현재 수치, 취임 대비 변화와 지난 턴 대비 변화를 함께 표시합니다. 그래프의 점을 누르거나 아래 선택 막대를 움직이면 해당 시점의 수치와 같은 턴에 내린 결정을 확인할 수 있습니다. 실업률과 위험처럼 낮을수록 좋은 지표는 하락했을 때 개선으로 표시합니다.

새 게임은 첫 사건에 대응하기 전부터 기록하며, 각 턴의 마지막 상태를 저장합니다. 이전 저장에는 과거 수치가 없으므로 업데이트 후 처음 연 시점부터 기록합니다.

새 게임은 10턴입니다. 업데이트 전에 진행하던 저장은 갑자기 종료되지 않도록 기존 20턴 규칙을 유지합니다.

## 실행

[게임 바로 하기](https://alexyoo49-netize.github.io/first-term/)를 열면 바로 플레이할 수 있습니다. 게임 진행은 같은 브라우저의 로컬 저장소에 자동 저장됩니다. 다른 기기와 동기화되지는 않습니다.

로컬 실행:

```sh
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.

## 수정과 빌드

`src/`에 게임 규칙, 사건과 인터페이스 소스가 있습니다. `layout.html`은 스타일, 글꼴과 초상을 포함합니다. `page-template.html`은 독립 실행과 브라우저 저장을 담당합니다.

```sh
python build.py
```

Python 3.9 이상이 필요하며 별도 패키지는 없습니다. 생성된 `index.html`을 소스 변경과 함께 커밋합니다. GitHub Pages는 `main` 브랜치의 루트에서 배포합니다.

게임 규칙 검증은 Node.js에서 `node test-game.cjs`로 실행합니다. 240판의 플레이, 계엄과 탄핵, 10턴 종료, 기존 20턴 저장 호환, 사건별 참모 조언, 지표 기록과 변화량 계산, 저장 용량을 확인합니다. 모든 인물과 시나리오 조합에서 설명용 시작 수치와 정책 예시를 검증하고, 해설을 읽어도 실제 저장과 난수 상태가 변하지 않는지 확인합니다.

이미지와 게임 글꼴은 내장되어 있습니다. 아이콘과 도움말 배치 라이브러리는 버전이 고정된 CDN에서 로드합니다.
